# EmbyMeshPatch

**EmbyMeshPatch** — это экспериментальный проект по созданию кастомной прошивки для устройств MeshCore. 

## Текущий статус проекта

На данный момент проект находится на самой ранней стадии разработки — **почти ничего еще не готово**. Текущий код представляет собой лишь базовый скелет. Прошивка пока не пригодна для повседневного использования или интеграции в рабочие устройства.

## Планы по разработке (To-Do)

В ближайшем будущем планируется реализовать следующий функционал:

* **Работа с SD-картой:** добавление возможности считывать конфигурационные файлы, профили и дополнительные данные напрямую с карты памяти.
* **Мультидисплейность:** поддержка одновременного подключения и вывода информации на несколько экранов.
* **Расширенная радиосвязь:** поддержка работы с несколькими радиомодулями одновременно для гибкой настройки меш-сети.
* **Стабилизация ядра:** написание базовых драйверов периферии и оптимизация энергопотребления.
